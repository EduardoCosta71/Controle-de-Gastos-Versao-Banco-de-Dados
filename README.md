## Controle de Gastos - Com Banco de Dados SQL SERVER

- Projetinho de controle de gastos para voçê controlar seu gasto do mes, ou do dia a dia.

## Funcionalidades

- Cadastrar gastos de -> Valor e Tipo de Gasto
- Soma dos Valores
- Média dos Gastos
- Gasto Minimo
- Gasto Maximo
- Excluir gasto
- Editar gasto


## Tecnologias

- Flask
- Python
- HTML
- CSS
